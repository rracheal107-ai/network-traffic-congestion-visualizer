    About this page and how to run live monitoring

    This page is the web (GitHub Pages) edition of the Network Traffic Congestion Monitoring and Optimization Visualizer, developed by Uwaegbulam Ugochi Racheal (2026). It uses the same rate computation, congestion classification and recommendation rules as the Python system (core.py).

    A web page cannot read a computer's network interface counters, so this edition offers two data sources: a simulated demo and a replay of the controlled live test, which plays back the 90 samples the Python system actually recorded while traffic was generated at known rates of 400, 800 and 1,200 KB/s (expected levels: Normal, Moderate, Congested on a 10 Mbps link).

    Live monitoring of a real computer runs with the Python application in this repository:

    pip install -r requirements.txt then streamlit run app.py (or double-click start.bat on Windows). The dashboard opens at http://localhost:8501.
